# Nitesh Kumar Singh — Portfolio Website

A hand-built, single-page site: plain HTML, CSS and JavaScript. It needs no build tools, no plugins and no external services.

## What's inside

| File | What it does |
|---|---|
| `index.html` | All page content: hero, About, Education, Experience, Blog, Contact |
| `styles.css` | Design: colours, fonts, layout for desktop, tablet and phone |
| `script.js` | Animations, menu, roadmap line, copy buttons, blog reader |
| `posts.js` | Blog posts. Add stories here (instructions inside the file) |
| `assets/` | Photos, fonts and the link-preview image |

## Put it online (free)

1. **GitHub:** create an account at github.com, make a new repository (for example `portfolio`), and upload everything in this folder.
2. **Netlify** (or Vercel): sign up with your GitHub account, choose **Add new site → Import from GitHub**, and pick the repository. Leave the build settings empty, then deploy.
3. **Domain (optional):** register `niteshkumarsingh.com.np` (free for Nepali citizens at register.com.np), then add it under **Domain settings** in Netlify.

From then on, every change pushed to GitHub goes live automatically.

## Making changes later

Connect GitHub to Claude and say what you'd like changed. Claude edits the repository, and Netlify updates the live site.

## Preview on your computer

Open `index.html` in a browser. Fonts load best through a local server, for example `python3 -m http.server` run from this folder, then visit http://localhost:8000.
